# 사진 기반 3D 복원 추가 실험 · 2026-10-31

목표는 사진에서 실제 3D 형상을 만드는 것이다. 영상 화질을 높이는 학습 대신, 깊이·점군·메시 생성과 구조 검증에 집중했다.

## 이번에 얻은 결과
학생회관 RGB 좌우 사진 52장으로 고밀도 3D 점 317,561개와 최종 삼각형 435,398개의 사진 기반 메시를 만들었다. 사진 대응으로 정점 위치를 추가 보정했고, 사진 텍스처를 포함한 GLB와 실제 미터 좌표 PLY를 내보냈다. LiDAR는 이 사진 메시의 표면 정점 생성 대신 좌표 정렬에 활용했다. 순수한 무보조 사진 전용 시스템이라고 부르지는 않는다.

다만 기존 LiDAR 기반 표면보다 구조가 확실히 정확해졌다는 근거는 얻지 못했다. 사진 모델에는 누락·거친 면·잘못 연결된 면이 남는다. 기존 구조 기준을 유지하고 새 형상들을 비교 후보로 제공한다.

## 작업 흐름과 주요 시도
1. 교수님 공식 RGB–NIR 공개 코드·모델과 데이터 구성을 확인했다. 후속 촬영 두 시퀀스, 총 389개 시점을 추가로 받았다. 실내 구간과 다른 실외 경로였고, 기존 건물과 신뢰할 공동 복원을 확보하지 못해 최종 형상에는 합치지 않았다. 실외 사진 대응은 392개 쌍을 선별 검사했다.
2. 기존 COLMAP 사진 위치를 활용해 OpenMVS 고밀도 복원을 구현했다. 기본 보정, 원본 해상도, 실제 13.2cm 스테레오 간격을 고정한 카메라 최적화, 짧은 기준 길이에 맞춘 관측 선택 조건을 비교했다. 직선에 가까운 이동 경로의 정렬 회전 모호성은 카메라 방향 제약으로 보완했다.
3. 교수님 연구실의 RGB–NIR 학습 모델은 5개 시점에서 시험했고, RGB 단독 RAFT-Stereo는 학생회관 26개 시점에서 깊이를 생성했다. 여러 시점에서 맞는 깊이만 융합하는 방법도 시험했지만, 제한된 관측과 깊이 오차 때문에 좋은 표면을 확보하지 못했다.
4. DA3 Small·Large로 여러 사진의 깊이를 함께 예측했다. 원본 예측과 LiDAR 보정 예측을 분리해 보존했다. 검증 촬영은 추론 배치·깊이 보정·표면 융합에서 제외했다. 카메라 위치는 기존 센서 추정을 재사용했다.
5. 신뢰할 사진 점만 기존 측정 구조에 보태는 Poisson 후보를 5·10·15cm 지원 거리 조건에서 비교했다. 5cm 후보는 두 검증 지표가 함께 좋아지지 않아 기준 모델을 교체하지 않았다.
6. 사진 대응으로 메시 정점을 직접 보정했다. 사진 단독 후보 안에서는 두 지표가 소폭 좋아져 최종 사진 모델에 적용했다. 이 개선이 기존 LiDAR 구조의 우위를 뒤집은 것은 아니다.

## 같은 조건의 구조 진단
| 표면 | 보간 깊이 지표 | 실제 LiDAR ray 지표 |
|---|---:|---:|
| 기존 구조 기준 | 20.38cm | 24.07cm |
| 사진 점 추가 · 5cm | 20.30cm | 24.12cm |
| 사진 복원 · 정점 보정 | 75.34cm | 77.19cm |
| DA3 Large + 깊이 보정 | 68.07cm | 70.15cm |

낮을수록 좋은 진단 점수다. 오차를 1m로 제한하며 빈 영역에도 1m 벌점을 준다. 두 열은 거리 정의와 표본이 달라 서로 직접 비교할 수 없다. 사진 모델의 관측 범위는 360도 LiDAR보다 좁다. 따라서 높은 점수에는 깊이 오차뿐 아니라 관측 누락도 반영된다. 이 값이 건물 전체의 실측 치수 정확도를 뜻하지 않는다.

표면 검증에서 6개 촬영 [5,13,21,29,37,45]를 제외했고 학생회관 4개 시점 [21,29,37,45]을 비교했다. 위치 추정에는 전체 촬영을 사용했고 같은 검증 자료를 반복 선택에 사용했다. 독립 외부 측량 시험은 아니다. 공개 RGB–NIR 학습 모델이 이 데이터셋으로 학습되었을 가능성도 배제하지 않는다.

## 파일을 보는 방법
- photo_surface_textured.glb: 최종 사진 기반 3D 표면과 사진 텍스처. Blender 등에서 바로 연다. 거친 면과 누락을 포함한 실험 결과다.
- photo_surface.ply / photo_dense_points.ply: 같은 사진 복원의 메시와 실제 고밀도 점군.
- baseline_surface.ply: 유지한 기존 구조 기준.
- hybrid_surface.ply / learned_surface.ply: 사진 점 추가 후보와 학습 깊이 후보.
- 공유 페이지에서 먼저 사진 복원을 회전하고, 기존 기준과 바꾸어 계단 모서리·벽·구멍을 비교한다. 색상은 끈 상태가 형상 판단에 유리하다.

## 남은 핵심
사진에서 기본 형상을 만드는 단계는 실행 가능한 코드와 실제 3D 파일로 확보했다. 완성도 높은 정밀 복원을 위해서는 같은 구조를 더 촘촘하고 다양한 각도에서 본 관측, 깊이와 카메라 위치의 더 강한 공동 제약이 필요하다. 관측하지 않은 면을 정확한 실측 형상처럼 채웠다고 주장하지 않는다.
