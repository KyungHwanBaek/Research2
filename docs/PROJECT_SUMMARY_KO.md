# 학생회관 사진 기반 3D 복원: 연구자·LLM 전달용 요약

## 목적과 환경

여러 시점 사진에서 학생회관 계단·입구·벽의 실제 3D 표면을 복원한다. 사진 같은 영상을 만드는 것과 기하학적으로 정확한 형상을 만드는 것은 구분한다. 장비는 Apple M4, 메모리 24GB이며 Metal은 지원하지만 NVIDIA CUDA는 없다.

핵심 자료는 공개 데이터 `01-26-15-41-24`의 RGB 좌우 사진 52장(26개 시점 × 좌우 카메라)과 같은 경로의 LiDAR 48개 스캔이다. RGB 사진과 LiDAR 거리 측정점은 서로 다른 자료다. 초기에는 다른 저조도 시퀀스와 RGB·NIR 희소 복원도 시험했다. 최종 OpenMVS 형상의 주된 영상 입력은 RGB다.

## 실제 완료한 작업

1. **COLMAP:** 사진의 특징 대응으로 촬영 위치·방향과 희소 점군을 얻었다. 초기 비교 점군은 전체 5,183개 점이며 뷰어 관심 영역은 1,667개다. 후속 스테레오 SfM 점군 수와 구분한다. 비교 사본의 크기와 좌표는 LiDAR 기준으로 맞췄다.
2. **LiDAR 누적:** 사진/COLMAP 위치 초기값과 기하 정합을 참고해 48개 스캔을 같은 공간에 누적했다. 약 164.8만 점이다. 사진 정보를 전혀 사용하지 않은 LiDAR 단독 SLAM 결과로 부르면 부정확하다.
3. **LiDAR 기반 표면:** 잡음 제거, 법선 추정, Poisson 표면 복원, 지지점이 부족한 면·작은 조각 제거 후 RGB 사진 색을 투영했다. 기본 표면은 2,120,479개 삼각형이다. 원시 점군에 색만 추가한 것이 아니다. 후속 기본 선택 모델은 이 형상을 유지하며 색을 개선했다. 사진 색을 얻지 못한 부분은 회색이다.
4. **사진 기반 표면:** COLMAP 계열 카메라 정보를 OpenMVS에 넘겨 52장 RGB 사진에서 깊이를 계산·융합하고 메시를 만들었다. 사진 대응에 따라 정점을 보정하고 텍스처 GLB를 내보냈다. 고밀도 점 317,561개와 최종 삼각형 435,398개다. LiDAR는 좌표·크기 정렬에 사용했고 표면 생성 점을 LiDAR에서 가져오지는 않았다. 무보조 순수 사진 전용 시스템으로도 부르지 않는다.
5. **다른 후보:** RGB–NIR 공개 모델 일부 시점, RAFT-Stereo, Depth Anything 3 계열 깊이 추정·융합과 보정, 일정 거리 이내의 사진 점을 LiDAR 구조에 추가하는 후보 등을 시험했다. 기존 LiDAR 기준을 명확히 능가하는 구조 개선은 확인하지 못했다.
6. **Gaussian 외관 모델:** Metal용 `msplat`으로 학습했다. 52장 중 42장 학습, 기존 선택 모델 약 211,669개 Gaussian. 추가 해상도·색상·분할 후보가 채택 기준을 넘지 못해 이전 선택 모델을 유지했다. 원본 CUDA 3DGS나 2DGS·AbsGS·Mip-Splatting 전체 알고리즘을 재현했다고 주장하지 않는다. Gaussian 장면과 삼각형 표면은 별개다.

현재는 같은 학생회관 구간을 복원한 결과다. 추가로 조사한 다른 실내·실외 경로는 신뢰할 연결을 확보하지 못해 최종 모델에 합치지 않았다. 보이는 공간 크기는 COLMAP의 최대 복원 가능 크기를 뜻하지 않는다.

## 평가와 한계

사진 모델은 외관상 구체적으로 보이지만 기존 LiDAR 표면보다 더 정확하다고 검증되지 않았다. 누락·뭉개짐·잘못 연결된 면이 남는다. 일부 스캔을 표면 생성에서 제외한 진단은 했으나 위치 추정은 전체 자료를 활용했고 동일 검증을 반복 사용했다. 건물 전체 실측 치수 정확도나 독립 외부 시험으로 해석하지 않는다.

보고서의 보간 깊이 지표·원시 LiDAR ray 지표에는 오차 상한과 누락 벌점이 포함된다. 표면 관측 범위가 서로 다르며 서로 다른 지표의 숫자를 직접 비교해서는 안 된다. 외관 PSNR·SSIM은 기하 정확도가 아니다. 웹 화면은 관심 영역과 점·삼각형 수를 줄인 표시본이다.

## 아직 하지 않은 것

- ETH3D, Tanks and Temples, DTU MVS 공식 벤치마크 실행
- 소개한 Neuralangelo·VGGT 등을 실제 실행·검증했다고 주장하는 것
- 구역별 신뢰도와 정렬 안정성을 이용한 새로운 결합 알고리즘 구현
- 논문 수준의 새 알고리즘 또는 세계 최초성 입증

후속 가설은 작은 카메라·센서 정렬 변화에도 같은 표면에 대응하는 사진 점만 선택해 LiDAR 구조를 보충하는 것이다. 이미 시험한 고정 거리 결합·국소 평면 보정과 구별해야 한다. 신뢰도·불확실성 융합에는 선행연구가 있으므로 독창성은 별도 검증이 필요하다.
