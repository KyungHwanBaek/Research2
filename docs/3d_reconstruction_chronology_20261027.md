**3D 복원 프로젝트 날짜별 작업 보고서**

기록 범위: 2026년 10월 5일~10월 27일 · 날짜와 시각은 한국 표준시(KST, UTC+9) 기준.

이 보고서는 프로젝트에 남아 있는 실행 로그, 평가 JSON, 당시 작성한 보고서와 공개 사이트 소스의 Git 이력을 대조해 작성했다. 최근 실험의 정확한 시각은 runs/*.json을 사용했다. 초기 작업은 로그에 찍힌 날짜와 당시 보고서를 우선했으며, 별도 실행 시각이 없는 문서 정리 작업은 Git 이력과 파일 기록을 보조 근거로 사용했다. 기록이 없는 날짜의 작업을 임의로 채우지 않았다. 데이터 이름의 01-26 또는 09-05는 촬영 시퀀스 식별자이며, 이 프로젝트에서 복원을 수행한 날짜와 다르다.

현재까지의 핵심 결과는 학생회관의 원시 LiDAR 48개를 연결한 표면과 사진으로 학습한 Gaussian 외관 모델이다. 학생회관 외관은 같은 검증 사진 기준으로 PSNR 약 23.28→24.14→24.66dB로 개선됐다. 가장 최근의 추가 학습에서는 이 최고치를 넘지 못해 기존 선택 모델을 유지했다. 물리적 구조의 실측 정확도가 이 비율로 높아졌다는 뜻은 아니다.

**2026년 10월 5일 — 환경 구축과 최초 COLMAP 기준선**

목적은 원본 자료를 읽고, 사진만으로 카메라 위치와 희소 3D점을 복원할 수 있는지 확인하는 것이었다.

- Apple M4·메모리24GB·macOS 환경을 확인하고 Python 환경과 COLMAP을 준비했다. NVIDIA GPU와 CUDA가 없는 점도 확인했다.
- 공식 데이터 중 16프레임 짧은 자료, 90프레임 어두운 실내 자료, 48프레임 밝은 실외 자료 등을 선별해 확보했다. RGB/NIR 이미지, storage.hdf5, 카메라 내부 보정값과 카메라–LiDAR 변환을 확인했다.
- 왼쪽 RGB 사진을 왜곡 보정하고 특징점 추출, 영상 간 대응, 카메라 위치 추정과 삼각측량을 수행했다.
- 어두운 실내 pilot은 90장 중3장만 연결되고 3D점46개였다. 별도 부분 구간의 exhaustive matching 후보는 42장 중11장과779점을 얻었다.
- 밝은 실외 자료에서는 주 구성요소26/48장, 3,071점을 얻었다.

산출물은 카메라 위치, 희소 점군 PLY, 수치 JSON과 초기 뷰어였다. 벽·계단 표면이 촘촘하게 복원된 결과는 아니었다. 어두운 실내보다 밝은 실외 자료가 더 안정적이어서 후속 실험의 주 대상으로 삼았다.

**2026년 10월 9일 — COLMAP 개선과 초기 Gaussian 렌더링**

목적은 최초 결과의 연결 수와 특징점을 늘리고, 사진 사이의 시점을 그릴 수 있는 외관 모델로 확장하는 것이었다.

- 카메라 내부값을 보정 파일에 고정하고, 원본 해상도와768px 축소 입력을 비교했다. 인접 사진 위주의 sequential matching과 전체 영상 쌍을 비교하는 exhaustive matching도 시험했다.
- 원본 해상도 sequential 주 모델은26/48장, 3,104점, 평균 재투영 오차0.479px였다. 768px exhaustive 주 모델은29/48장, 3,518점을 얻었다. 서로 다른 설정의 결과를 하나의 모델 수치로 섞지 않았다.
- CLAHE 대비 보정과 다른 밝은 실외 촬영도 시험했으나 새 주 기준선으로 바꿀 만큼 연결성이 개선되지 않았다.
- 희소 점으로 Delaunay 표면을 만들어봤다. COLMAP dense stereo는 CUDA가 없어 실행하지 못했다. 희소 점을 이은 삼각형을 정밀한 건물 표면으로 해석하지 않았다.
- Mac Metal용 msplat으로3D Gaussian Splatting을 학습했다. 3,000회 시험과8,000회 확장 시험을 진행했고, 8,000회 결과에서351,281개 Gaussian과48개 보간 시점 렌더링을 만들었다. 이 초기 값은 이후 동일 검증 분할 평가와 직접 비교할 수 있는 성능 지표가 아니다.
- 친구의 LiDAR 결과와 같은 긴 경로인09-05-17-34-36도 확보해 시작·중간·후반 부분 구간과 전체 경로 RGB 복원을 비교했다. 최종 all-frame 결과는1,823장 중1,821장이 등록됐지만10개의 별도 모델로 나뉘었고, 점은 합계58,409개였다.

이날 확인한 핵심은 사진이 많이 등록돼도 하나의 연속된 지도가 된 것은 아니라는 점이다. 초기 경로가 일자처럼 보였던 원인에는 시작 부분만 사용한 것도 있었고, 전체 사진을 사용해도 회전·관측 단절로 여러 조각이 남았다.

**2026년 10월 10일 — NIR 비교와 복원 조각 병합**

목적은 RGB에서 끊긴 구간을 NIR로 보완할 수 있는지, 별도 COLMAP 모델을 검증 가능한 방식으로 연결할 수 있는지 확인하는 것이었다.

- 학생회관 관련48장 NIR에서 주 모델26장·2,207점, 다른 모델14장·1,897점을 얻었다.
- 긴 경로의 NIR1,823장에서는 중복을 제외한1,782장이 등록됐지만 역시10개 구성요소로 나뉘었다. NIR만 사용해 전역 경로 문제가 해결되지는 않았다.
- COLMAP model_merger로 겹치는 일부 조각을 병합했다. 예를 들어 RGB 일부 조각267장·11,740점, NIR 일부 조각569장·21,218점의 병합 결과가 있었다.
- 근거가 약한 연결은 공식 merger가 거부했다. 보기 좋게 이어 붙인 route-stitched 시각화도 만들었지만, 이것을 정밀하게 정합된 최종 지도나 학생회관 LiDAR 융합 입력으로 쓰지 않았다.

산출물은 RGB/NIR 구성요소별 점군·뷰어, 비교 표와 경로 합본 시각화였다. NIR의 보완 가능성을 확인했으나 독립된 조각의 위치·크기·방향을 모두 해결한 결과는 아니었다.

근거: README.md의 NIR/Route-Stitched 항목, results/metrics/rgb_nir_colmap_comparison.csv, results/metrics/stitched_colmap_0905_report.json.

**2026년 10월 19일 — LiDAR 없이 긴 경로를 고밀도 복원**

이날의 첫 작업은 기존 긴 경로의 희소 COLMAP 결과를 좌우 RGB/NIR 기반 고밀도 지도와 표면으로 확장하는 것이었다. 이 단계에서는 LiDAR 점·LiDAR 위치·카메라–LiDAR 변환을 사용하지 않았다.

- 1,823프레임 중3프레임 간격으로609개의 스테레오 카메라 시점을 추적했다. 그중306개 시점의 깊이를 융합했다.
- RGB9개 시점의 대응으로 스테레오 회전과 이동 방향을 보정했다. 별도5개 시점에서 수직 정렬 오차는5.126→0.209px, 신뢰 가능한 RGB 깊이 픽셀 비율은9.89→44.77%로 개선됐다. 이것은 영상 정렬·깊이 유효 범위 지표이지 절대3D 오차는 아니다.
- RGB/NIR 깊이, 좌우 일관성, 여러 시점의 깊이 일치 조건과 voxel 융합을 적용했다. 자세의 높이·기울기 누적 오차를 줄이기 위해 완만한 평지 가정을 적용했으며, 가정을 쓰지 않은 결과도 보존했다.
- 초기 고밀도 결과는 컬러 점5,514,730개, 표면 삼각형1,306,350개였다. 경로는 여전히3개의 독립 구간이었다. 구간 범위는 원본프레임0~1548, 1551~1641, 1644~1822였다.
- 한 지역의61장 사진에서53장 학습·8장 검증으로3DGS를 비교했다. 희소 초기화12,000회는26.448dB, 스테레오 점 초기화는23.414dB였다. 더 촘촘한 초기 점이 외관을 자동으로 개선하지는 않았다. 희소 초기화를30,000회 학습한26.935dB·SSIM0.8385 모델을 선택했다.

이날의 두 번째 작업은 좌우 카메라의 관측을 함께 사용하는 native PyCOLMAP/Ceres bundle adjustment와 공유 사이트 구축이었다.

- 좌우 카메라를 고정 rig로 구성하고, 실제 SIFT 좌우 관측과 시간 간 특징점 track을 이용해609개 시점의 자세·3D점을 공동 보정했다.
- 보정 결과를 모두 적용하는 대신 별도의 dense-depth 진단으로 구간별 혼합 비율을 선택했다. 주 구간의 상대 깊이 오차 중앙값은3.010→2.872%, 깊이 일치율은76.06→79.58%였다.
- 최종 긴 경로 구조는 컬러 점6,064,545개, 표면 삼각형1,255,464개가 됐다. 점 수는 세 독립 구간의 합계이며 하나의 연결된 전역 모델 수치는 아니다.
- 공동 BA 카메라를 쓴 새 렌더링은24.517dB로 기존26.935dB보다 낮았다. 구조 진단이 개선됐어도 외관은 기존 모델을 유지했다.
- 점군·표면 회전/확대, 원본 사진, 동영상과 구간별 공유 링크를 제공하는 공개 사이트를 배포했다. 사이트 소스의 첫 공개 결과 커밋 시각은10월19일18:57:04다.

**2026년 10월 21일 — 학생회관 원시 LiDAR와 COLMAP 결합**

목적은 학생회관 중정·계단·입구를 우선 복원하는 것이었다. 친구가 만든 누적 지도·궤적 파일은 제공받지 않았으므로, 프로젝트에 있던 원시 LiDAR48개에서 지도를 직접 만들었다.

- 원래 COLMAP의 두 구성요소를 중복 없이40개 카메라·5,183개 희소점으로 정리하고, LiDAR 깊이로 크기를 미터 단위에 맞췄다.
- KISS-ICP 단독 추적, 영상 특징점+LiDAR 깊이 PnP, COLMAP 상대 위치, 다중 해상도 robust ICP, FPFH/RANSAC 회전 복구와 포즈 그래프를 비교했다.
- 동일한37개 시점 쌍과 ICP에 쓰지 않은 반환점으로 비교했을 때, 원래 미터 보정 COLMAP 대비 선택 포즈 그래프는25cm 이내 겹침71.71→77.81%, 대응점 접평면 오차 중앙값5.454→2.690cm였다. 이 값은 스캔 간 일관성 진단이다.
- 카메라·특징점·LiDAR 접평면의 공동 보정도 시험했다. 남겨둔 관측의 재투영 오차 중앙값은4.027→0.524px로 줄었지만, LiDAR 스캔 일관성은 오히려 나빠 구조에는 채택하지 않았다.
- TSDF와 Poisson 표면을 비교했다. 센서3m 이내 반환점이 잘못된 차폐 면을 만드는 문제를 발견해 제외하고, 실제 관측에서 너무 먼 추정 표면을 제거했다.
- 최종 구조는48개 촬영 시점, 전체 LiDAR 점1,648,179개, 컬러 점232,136개와 Poisson 삼각형2,120,479개였다. 웹에서는 전송량을 줄인 축소 표면을 표시했다.
- 원본 COLMAP, 공동 보정 희소점, LiDAR 초기 점으로 외관을 비교했다. COLMAP12,000회가 당시 native 평가23.281dB·SSIM0.7181로 가장 좋았다.30,000회는23.169dB, LiDAR 초기화는15.778dB여서 채택하지 않았다.

원본195개 파일 및 각 라운드의 주요 이전 결과를SHA-256으로 확인했다. runs/에는 명령·시각·종료 상태, logs/에는stdout/stderr, source_snapshot/에는 코드, 각 JSON에는 평가와 선택 근거가 있다. 공개 ZIP은 가벼운 재현 기록이며 원본 사진/HDF5·전체 표면·학습 체크포인트를 모두 담은 패키지가 아니다. 큰 산출물은 로컬 실험 폴더에 보존했다. 배포 후 영수증과 HTTP 검증은 해당 라운드의 로컬 동반 기록에 저장했다.

**아직 실행하지 않은 후속 계획**
