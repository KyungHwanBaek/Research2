# Adaptive 3D Scene Reconstruction Pilot

Latest result (2026-10-21): [student union RGB/COLMAP + LiDAR reconstruction](https://stereo-reconstruction-lab-kyunghwan.sillycod2.chatgpt.site/student-hall.html). Built directly from the 48 raw LiDAR scans and RGB photographs in `01-26-15-41-24`; no friend-provided map was available. Compared registration, joint refinement, TSDF/Poisson meshes, and four Gaussian training runs. Final geometry: 48 poses, 232,136 colored points, 1,648,179 LiDAR points and 2,120,479 mesh triangles. See [methods, measurements and limitations](STUDENT_HALL_LIDAR_REPORT.md). The public page includes original COLMAP comparison and the best measured rendering; the geometry and rendering use separately selected models.

Latest result (2026-10-19): [public reconstruction gallery](https://stereo-reconstruction-lab-kyunghwan.sillycod2.chatgpt.site) and [joint stereo optimization report](JOINT_STEREO_PUBLIC_REPORT.md). Friends can open the public link without a local server. The previous [local stereo gallery](results/stereo_improved_0905/index.html) and [first improvement report](STEREO_IMPROVEMENT_REPORT.md) are preserved. Historical RGB-left-only baselines remain below.

Right RGB and LiDAR are not mixed into the initial COLMAP baseline. NIR-left is now used as a follow-up diagnostic modality to test whether infrared imagery improves COLMAP connectivity on the same routes.

The all-frame RGB and NIR runs are the cleanest comparison because they use every available frame from the same route. RGB registers slightly more unique frames, while NIR merges the late-route portion into a larger single component. Neither produces one global route like the LiDAR/KISS-ICP result. The breakage is a component-stitching/global-connectivity problem, not merely a lack of RGB frames. This is an important modality difference: LiDAR/KISS-ICP can accumulate metric scans along a route, while image-only COLMAP needs enough visual overlap and stable features to bridge every section. The output remains sparse SfM with arbitrary monocular scale, not a metric LiDAR SLAM map.

For `09-05-17-34-36`, NIR changes the shape of the result more substantially:

- RGB all-frame largest component: 444 frames, frames 28..471, 12,098 sparse points
- NIR all-frame largest component: 545 frames, frames 1142..1766, 19,568 sparse points
- RGB all-frame unique registered frames: 1,788 / 1,823
- NIR all-frame unique registered frames: 1,782 / 1,823
- Both runs split into 10 disconnected components

Interpretation: NIR does not solve global reconstruction by itself, but it gives a complementary late-route component that is larger than the corresponding RGB components. That makes NIR valuable for the next fusion stage: compare RGB/NIR component ranges, then use LiDAR trajectory or known frame order as the metric/global backbone.

This was done in two layers. First, COLMAP `model_merger` was tried wherever components shared registered images. It successfully merged some local clusters, such as RGB `(9+5)+4` and NIR `1+7`, but rejected several weak bridges. ## Reproduction

Set up:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -U pip
.venv/bin/python -m pip install -r requirements.txt
brew install colmap
```

Download one official archive:

```bash
.venv/bin/python scripts/download_dataset.py --filename 01-24-08-49-46.tar.gz
python3 scripts/extract_archive.py data/raw/01-24-08-49-46.tar.gz data/extracted
```

Inspect:

```bash
.venv/bin/python scripts/inspect_dataset.py \
  data/extracted/01-24-08-49-46 \
  --json-out results/metrics/dataset_inspection_01-24-08-49-46.json
```

Prepare RGB-left images:

```bash
.venv/bin/python scripts/prepare_colmap_images.py \
  data/extracted/01-24-08-49-46 \
  data/colmap_input/rgb_colmap_pilot/images \
  --start 0 --count 90 --stride 1 \
  --undistort-calibration data/extracted/01-24-08-49-46/calibration.npz \
  --contact-sheet results/figures/rgb_colmap_pilot_contact_sheet.jpg
```

Run COLMAP sparse:

```bash
bash scripts/run_colmap_sparse.sh \
  data/colmap_input/rgb_colmap_pilot/images \
  experiments/rgb_colmap_pilot \
  '1794.6042411717074,1796.1937643331776,697.0019767243274,539.1660652197719'
```

Summarize and visualize:

```bash
.venv/bin/python scripts/summarize_colmap.py \
  experiments/rgb_colmap_pilot/sparse/0 \
  results/metrics/rgb_colmap_pilot.json \
  --input-image-count 90

MPLCONFIGDIR=$PWD/logs/mplconfig XDG_CACHE_HOME=$PWD/logs/cache \
  .venv/bin/python scripts/visualize_reconstruction.py \
  experiments/rgb_colmap_pilot/sparse_text \
  --out results/figures/rgb_colmap_pilot_sparse_overview.png
```
